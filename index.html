Context Switcher 0.3.0.0

An AI-assisted personal work-context application for Windows (development / sideload build).

Install / subscribe (App Installer)

First time - trust the signing certificate

This is a self-signed development build. Download ContextSwitcher-Dev.cer and import it once (elevated PowerShell):

Import-Certificate -FilePath ContextSwitcher-Dev.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople

Then open the Install button above. App Installer checks this page on launch and in the background, and offers new versions automatically.
