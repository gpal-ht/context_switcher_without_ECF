# MVP Scope

## Initial User

The initial user is the project owner.

This is a personal-use application before it becomes a general productivity product.

## First Problem to Solve

Help the user switch context from one project to another intentionally and reliably.

The app should reduce the mental cost of ending one work session and starting another.

## MVP Goal

The MVP should help the user answer:

1. What was I working on?
2. What did I finish?
3. What is still open?
4. What should future-me know?
5. What am I working on next?

## Product Evolution

### Stage 1 — Assisted Context Switching

The app guides the user through ending one project session and starting another.

### Stage 2 — Seamless Context Switching

The app makes switching between projects smoother by remembering project state, notes, open questions, and next actions.

### Stage 3 — Workday Operating System

The app becomes the central place where the user plans, executes, reviews, and transitions through the entire workday.

## Current Non-Goals

The MVP will not attempt to:

- manage the entire workday
- integrate with calendars
- control other applications
- automate project decisions
- support multiple users
- sync to cloud storage
- provide complex AI recommendations

## MVP Success Criteria

The MVP succeeds if the user can:

- start a work session for a project
- receive a wrap-up prompt
- record what happened during the session
- choose the next project
- resume the next project with less mental friction
