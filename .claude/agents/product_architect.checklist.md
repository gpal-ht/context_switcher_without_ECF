# Product Architect Review Checklist

Use this checklist when reviewing any feature proposal.

## Product Alignment

* [ ] Does the feature support the product mission?
* [ ] Does it strengthen Context Switcher as a work operating system?
* [ ] Does it belong in the current product phase?
* [ ] Does it avoid unnecessary scope expansion?

## User Value

* [ ] What user problem is being solved?
* [ ] Is the problem clearly defined?
* [ ] Is there evidence that this problem matters?
* [ ] Is there a simpler solution?

## Product Principles

* [ ] Does it reduce cognitive load?
* [ ] Does it preserve user agency?
* [ ] Does it improve context rather than simply collect more data?
* [ ] Does it increase trust?

## MVP Impact

* [ ] Is this required for the MVP?
* [ ] Can this be postponed?
* [ ] Can the feature be split into smaller increments?

## Risks

* [ ] Feature creep
* [ ] Increased cognitive load
* [ ] User confusion
* [ ] Long-term maintenance cost

## Review Result

Choose one:

* Approve
* Approve with recommendations
* Needs redesign
* Block

Provide a concise rationale for the decision.
